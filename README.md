# 富江破甲（破甲）— DeepSeek Harness 插件

**富江破甲 · 破甲 · Fujiang Pojia | v0.20.11**

富江破甲是面向 DeepSeek Harness 的提示词配置、技能库与安全评估工作流插件。它旨在帮助 AI 理解合法授权任务的上下文，减少不必要的拒答，改善任务连续性，并把知识检索、验证记录和漏洞报告连接起来。实际表现取决于模型、服务商政策、环境配置与任务内容，不保证所有模型或请求都能执行。

## 功能

- 按需下载和接入 [AboutSecurity](https://github.com/wgpsec/AboutSecurity) 技能库及 [REA](https://github.com/morluto/rea) 工具，提供技能搜索、读取入口。
- 内置 CVE / PoC 知识库，支持按资产指纹查找候选知识条目。
- 提供 AI 工具接口，用于更新任务、记录验证步骤和写入漏洞报告；AI 是否调用取决于当前会话和工具配置。
- 管理侦察、指纹识别、匹配、验证、利用、横向分析、报告等阶段，记录目标与进度；自动续跑默认最多 8 轮，支持完成标记。

## 下载与安装

下载 [v0.20.11 安装包](./dsh-prompt-custom-official-0.20.11-verified.zip)，解压后使用。兼容 DeepSeek Harness **>=0.2.1-rc.5 且 <0.3.0**，默认安装到 Desktop 配置。

1. 先运行一次官方 Harness Desktop，完成配置初始化。
2. 手动完全退出 Harness，再运行解压目录中的 `install.cmd`。
3. 安装完成后手动重新打开 Harness，检查插件面板并按需下载技能库、启用知识库。

安装器不负责自动关闭或重启 Harness，也不支持 `-NoRestart` 参数；原包内相关旧说明以这里为准。
